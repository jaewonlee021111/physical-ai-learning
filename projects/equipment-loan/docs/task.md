# 실행한 작업 요청

목적: 장비 대여 R01~R05를 표준 라이브러리만 사용해 구현한다. inventory.py에서 순수 상태 변경과 파일 I/O를 분리하고, app.py에서는 CLI를 제공한다. 재고 0·초과 반납·미선택·손상 파일을 오류로 처리하고 기존 상태를 보존한다. 테스트에서 대여·반납 성공, 경계 실패, 저장·복원·손상 보존을 확인한다. 문서와 테스트를 포함해 재실행할 수 있는 결과를 남긴다.

변경 요청: 기존 입력을 직접 수정하는 대신 deepcopy로 반환값을 만들고, 임시 파일+os.replace로 저장을 교체해 실패 경로를 분명히 했다.
