# 요구사항과 완료 조건

| ID | 요구사항 | 확인할 결과 |
| --- | --- | --- |
| R01 | 이름·전체·남은 수량 표시 | list에서 모든 장비와 세 값 출력 |
| R02 | 재고가 있으면 대여 | available 1 감소, 원자적 JSON 저장 |
| R03 | 재고 0·미선택·없는 번호 거절 | 오류와 함께 원본 불변 |
| R04 | 반납 시 1 증가, 전체 수량 초과 금지 | 상한 경계 검증 |
| R05 | 재실행 복원, 손상 파일 보존 | 별도 실행에서 상태 유지, 잘못된 파일 미수정 |

범위는 단일 사용자 CLI다. Python bool은 int의 하위 타입이지만 수량에서는 허용하지 않는다. 파일이 없거나 잘못되면 자동 초기화하지 않는다.
