## 핵심 정리
| 도구·명령 | 역할 |
| --- | --- |
| Git | 로컬 버전 기록 |
| GitHub | 원격 저장소와 협업 서비스 |
| GitHub Desktop | Git 작업을 화면에서 수행 |
| save | 작업 파일 저장 |
| add | 다음 커밋에 넣을 변경 선택 |
| commit | 선택한 변경을 로컬 기록으로 생성 |
| push | 로컬 커밋을 원격에 전달 |
| fetch | 원격 기록 확인 |
| pull | 원격 기록을 가져와 현재 브랜치에 반영 |

## 기본 흐름
```sh
git status
git diff
git add physical-ai/
git diff --cached
git commit -m "docs: update physical AI learning notes"
git push
```
add 뒤에 파일을 또 고쳤다면 작업 파일과 스테이징 내용이 달라질 수 있다. commit 전에 두 diff를 확인한다.

## 협업과 포트폴리오
- README에 목적·실행 방법·입출력·제한·출처를 쓴다.
- 프로필 README, 배지, 이미지·GIF는 실제 결과를 설명하는 데 사용한다.
- 기능 작업은 브랜치에서 변경하고 PR로 차이를 검토한다.
- 충돌이 나면 양쪽 의도를 확인하고 편집·실행 후 해결 커밋을 남긴다.
- 토큰·비밀번호·개인정보를 저장소에 넣지 않는다.
