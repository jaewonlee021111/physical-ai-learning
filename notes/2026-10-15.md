## 핵심 정리
- `def`는 함수 정의, 괄호를 붙인 호출은 실행이다. 매개변수는 받는 이름, 인자는 실제 전달하는 값이다.
- `print`는 화면에 보여 주고, `return`은 호출한 곳으로 결과를 돌려준다.
- 기본값·키워드 인자로 함수의 입력을 분명히 한다. 함수 내부 변수의 범위를 구분한다.
- 중첩 리스트·딕셔너리는 얕은 복사만으로 내부 자료가 분리되지 않는다.
- `enumerate`는 순번, `zip`은 두 목록의 짝을 처리한다. 길이가 다르면 기본 zip은 짧은 쪽에서 끝난다.
- 빈칸·잘못된 숫자·범위 밖 숫자는 서로 다른 상태로 남긴다.
- CSV 읽기 → 변환 함수 → 검사 함수 → JSON 저장처럼 역할을 나눈다.
- 예외 메시지에서 파일·줄 번호·오류 종류를 확인한다. 확인되지 않은 값을 임의로 정상 데이터로 바꾸지 않는다.

## 복습 예제
[센서 로그 변환기](../examples/sensor_pipeline.py)는 Python 표준 라이브러리만 사용한다.
- 입력: [가상 CSV](../data/readings.csv)
- 보존: sensor_id와 입력 원문
- 처리: 정상 / 미측정 / 범위 밖 / 잘못된 숫자
- 출력: 실행 위치의 `output/sensor-report.json`
- `NaN`·무한대는 유효한 측정값으로 받지 않는다.
- 정상 값만 평균에 포함한다.

이 코드는 공개 수업 주제에 맞춰 새로 작성한 복습 예제이며, 강사 원본 또는 실제 제출 과제라는 뜻은 아니다.
