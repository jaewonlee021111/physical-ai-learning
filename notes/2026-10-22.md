# 2026-10-22 · 웹에서 비전 파이프라인까지

## 수업 흐름

오전에는 전날 만든 기획서를 바탕으로 개인 포트폴리오를 제작하고, CSS·반응형 Grid·JavaScript 이벤트·React의 컴포넌트 개념을 복습했다. 오후에는 카메라 → 프레임 → 전처리 → YOLO 추론 → 박스 시각화 → 브라우저 출력으로 연결했다. 마지막에는 다음 하드웨어 실습을 위한 두 프로젝트를 준비했다.

코드와 녹화 상대 시간은 [10/22 실습](../labs/2026-10-22/README.md)에 있다.

## 코드에서 적용한 판단

카메라를 HTTP 요청마다 새로 열지 않고 한 생산자가 읽는다. 여러 브라우저는 lock/condition으로 보호한 최신 프레임을 공유한다. 느린 추론 때문에 오래된 영상이 큐에 계속 쌓이지 않도록 최신 결과를 유지하고, N프레임마다 추론하는 설정을 분리했다. 생략된 프레임에는 이전 박스를 사용하되 이를 화면과 로그에 표시한다.

단계 함수의 XML docstring에서 설명을 읽어 대시보드 노드를 만들고, SSE로 200ms마다 상태를 보낸다. 탐지 모델 안의 전처리·추론·후처리는 `Results.speed`를 사용한다. 외부 함수 호출 전체 시간과 내부 시간은 중첩될 수 있어 무조건 합산하지 않는다.
