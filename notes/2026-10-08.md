## 핵심 정리
- 데이터는 관측한 값이다. 해석과 결론은 출처·수집 조건과 함께 구분해서 기록한다.
- 정형은 행·열과 일정한 스키마, 반정형은 JSON 같은 키와 중첩 구조, 비정형은 자유로운 문서·이미지·음성 등이 대표적이다.
- 숫자로 적힌 식별자와 계산할 수 있는 수량은 다르다. 센서 ID `001`은 문자열로 보존한다.
- 명목·서열·이산·연속이라는 통계적 의미와 Python의 `str/int/float/bool/None`이라는 자료형은 별개다.
- 한 행의 관측 단위와 고유 키를 먼저 정한다. 같은 센서의 여러 측정에는 센서 ID만으로 부족할 수 있다.
- CSV는 헤더·구분자·따옴표·빈칸 규칙이 중요하다. Python의 기본 CSV 읽기는 값을 문자열로 돌려준다.
- JSON은 객체·배열을 중첩할 수 있다. JSON의 `true/false/null`은 Python의 `True/False/None`에 대응한다.

## 직접 설계해 보기
| 필드 | 의미 | 저장 규칙 |
| --- | --- | --- |
| sensor_id | 센서 식별자 | 문자열, 앞자리 0 보존 |
| timestamp | 측정 시각 | 시간대 포함 문자열 |
| value | 측정값 | 숫자로 변환, 미측정은 null |
| unit | 단위 | 예: °C |
| status | 검사 결과 | 정상 / 미측정 / 범위 밖 / 잘못된 숫자 |

CSV 빈칸을 자동으로 0으로 바꾸면 평균이 달라진다. 원문을 보존하고 변환 결과를 별도 필드로 남긴다.
