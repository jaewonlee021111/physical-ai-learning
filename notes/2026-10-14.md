## 핵심 정리
- 코드를 저장하는 일과 실행하는 일은 다르다. 수정 후 저장하고 올바른 파일을 실행한다.
- 변수는 이름에 값을 연결한다. 재대입하면 이후에 사용하는 값이 바뀐다.
- `input()`의 결과는 문자열이다. 숫자 계산에는 명시적인 변환과 입력 검사가 필요하다.
- `+`는 숫자끼리 덧셈, 문자열끼리 연결이다. `"2" + "3"`은 `"23"`이다.
- `if/elif/else`는 조건의 순서와 경계값을 확인한다. 들여쓰기가 실행 범위를 결정한다.
- 리스트의 인덱스는 0부터 시작한다. 반복문으로 누적·분류할 수 있다.
- 딕셔너리는 필드 이름으로 값을 찾는다. 여러 측정 기록은 리스트 안에 딕셔너리를 넣어 표현할 수 있다.

## 조건과 반복 예제
```python
readings = [21.0, None, 40.0]
for value in readings:
    if value is None:
        print("미측정")
    elif 0 <= value <= 35:
        print("정상")
    else:
        print("재확인")
```
여기서 0~35는 복습용 임의 기준이다. 실제 센서의 정상 범위는 요구사항으로 정해야 한다.
