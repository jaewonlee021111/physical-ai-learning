# 표지판 반응형 4륜 라즈봇 · 개인 기획 초안

## 1. 문제·목표·범위

목표 그림·이동 표지판을 카메라로 인식하고 접근한 뒤 GOAL에서는 정지, 좌우 화살표에서는 회전하는 4륜 로봇이다. 먼저 GOAL 하나의 접근·정지를 완성한다. 손동작은 표지판 동작 완성 이후 확장이다. 아래 수치는 초기 시험값이며 실물 측정 후 조정한다.

## 2. 역할과 결정

| 역할 | 책임 경계 | 담당 상태 |
| --- | --- | --- |
| 인식 | 신호 종류·위치·크기·관측 시각 제공 | 이름 미배정 |
| 모터·센서 | 모터 명령 적용·거리 측정·유효 여부·90도 회전 보정 | 이름 미배정 |
| 접근·정지 | 상태에 맞는 조향·속도·정지 명령 계산 | 이름 미배정 |
| 통합 | 상태 전환 시점·예외·시험 연결 | 이름 미배정 |

팀장·팀원 이름과 최종 승인권자는 팀에서 확인한다. 이 문서는 개인 정리 초안이다.

## 3. 요구·작업·시험 연결

| 요구 | 동작과 수용 기준 | 작업 | 시험 |
| --- | --- | --- | --- |
| R01 | GOAL·좌·우를 0.3~1m에서 10회 중 9회 이상 인식 | W01 인식 모듈 | T01 |
| R02 | 25cm에서 거리 오차 ±2cm, 최근 5회 중간값 | W02 거리 측정 | T02 |
| R03 | 화면 중앙으로 조향, 60cm 초과 보통·25~60cm 느림·25cm 이내 정지 | W03 접근 제어 | T03 |

| R06 | 센서 3회 연속 실패 시 정지, 유효값 3회 연속 후 조건 재판단 | W04 예외 처리 | T06 |

## 4. 구조와 인터페이스

카메라 → 인식 결과 → 상태 관리자 → 접근 제어 → 모터로 연결한다. 초음파 모듈은 거리·유효 여부·관측 시각을 제공하고, 가까운 장애물과 센서 연속 실패에 대한 정지가 일반 주행보다 우선한다.

인식의 최소 전달 항목은 신호 종류, 화면 위치·크기, 관측 시각이다. 거리 모듈은 거리 cm, 유효 여부, 관측 시각을 전달한다. 명령은 속도·회전·정지다. 구체적인 필드명·자료형·주기는 코드 작성 전에 합의한다.

## 5. 순서와 완료 조건

1. 카메라 인식과 모터·센서를 각각 시험한다.
2. GOAL 한 장을 놓고 접근·정지한다.
3. 좌우 회전과 다음 표지판 탐색을 추가한다.
4. 신호 소실·센서 오류·중복·장애물을 시험한다.
5. 실행 코드·설정·배선·시험 결과와 다음 작업을 함께 전달한다.

완료는 코드 존재만으로 판단하지 않는다. 해당 요구의 시험, 결과·증거, 실행 안내, 변경 검토까지 갖춰야 한다.

## 6. 위험과 확인

| 위험 | 확인·대응 |
| --- | --- |
| 초음파가 표지판 대신 다른 물체를 측정 | 판 크기·높이·센서 방향을 맞추고 실제 코스에서 확인 |
| 인식이 늦거나 표지판을 놓침 | 관측 시각을 기록, 2초 이상 소실 시 정지·재탐색 |
| 회전각이 바닥·배터리에 따라 달라짐 | 실제 90도 회전 시간을 측정하고 조건별 기록 |
| 같은 표지판 재실행 | 최소 대기와 화면 이탈 조건 결합 |

## 7. 시험 결과

T01~T07 모두 **NOT_RUN**. 이 갱신에서는 기획 문서를 작성했으며 실물·새 제어 코드 시험을 수행하지 않았다. 결과 기록에는 입력 조건·버전·기대·관찰·판정·증거를 포함한다.

## 8. 변경·인계

수치나 범위 변경 시 이유와 영향을 요구·코드·시험에 함께 반영한다. 다음 작업은 W01/W02의 실제 보드·카메라 환경 확인과 데이터 계약 확정이다. 손동작 추가는 기본 동작 검증 뒤 별도 변경으로 관리한다.
