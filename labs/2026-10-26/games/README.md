# 조이스틱 → 웹 게임 2개

기존 게임의 이미지·이름·캐릭터를 복제하지 않고 도형으로 독립 구현했다.

- **Signal Runner**: 플랫폼 이동, 점프, 수집, 발사, 적 충돌, 생명·낙하·목표 도달.
- **Sky Patrol**: 상하좌우 이동, 적·적 탄환, 발사, 폭탄, 생명·점수·목표 달성.

## 실행

저장소 루트에서:

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory labs/2026-10-26
```

`http://localhost:8000/games/`를 연다. 키보드는 방향키 이동, Z 점프, X 공격, C 폭탄이다. 게임 선택·재시작·일시정지를 제공한다. 점프와 폭탄은 누르는 순간 한 번, 공격은 누르는 동안 반복된다. 탭에서 포커스가 빠지면 키 입력을 비우고 시간 차이를 제한해 갑자기 이동하지 않게 했다.

## 실제 UNO 연결

1. [배선표](../uno/README.md)를 따라 `joystick` 환경을 업로드한다.
2. 조이스틱 A0/A1, SW D2, 점프 버튼 D3, 공격 버튼 D6를 연결한다. 버튼은 GND로 닫히고 내부 풀업을 쓴다.
3. PlatformIO/Arduino의 시리얼 모니터와 Python 모니터를 닫는다.
4. Web Serial 지원 Chrome/Edge의 localhost/HTTPS에서 **UNO 연결**을 누르고 본인 포트를 선택한다. 속도는 115200이다.
5. 조이스틱에서 손을 뗀 뒤 **중립 보정**을 누른다. 설치 방향에 따라 X/Y 반전을 선택한다.
6. 연결 해제로 리더와 포트를 정리한다. 페이지 새로고침 뒤에는 다시 연결한다.

프로토콜은 50Hz JSON Lines다. 예시는 구조를 설명하는 값이며 실측 로그가 아니다.

```json
{"type":"input","seq":1,"x":512,"y":512,"jump":0,"attack":0,"bomb":0}
```

범위를 벗어나거나 부팅 문구인 줄은 입력으로 쓰지 않는다. ADC 0~1023·버튼 0/1을 검증하고, 중립 주변 데드존을 둔다. 마지막 유효 입력이 300ms 이상 지났으면 오래된 조작을 유지하지 않고 키보드 입력으로 돌아간다. 브라우저 미지원 시 키보드 사용 안내를 보여 준다. 모바일 Safari 지원이나 실제 장치 연결 성공을 주장하지 않는다.
