## 무엇을 배우나

표준·사례 관찰 → 개인 스케치 → 센서/LED 연결 → 화면 제작 → 정상·실패 확인 → 실행 원본 전달로 이어진다. 서버나 DB 없이 P01 UNO와 브라우저의 Web Serial로 시작한다.

## 연결과 데이터의 의미

| 항목 | 공개 P01 예제 기준 |
| --- | --- |
| 핀 | LED D8, 버튼 D2, 가변저항 A0, CdS A1, DHT11 D4, I2C LCD A4/A5 |
| 통신 | 시리얼 115200, 실제 포트는 사용자가 선택 |
| 브라우저 | 지원되는 PC Chrome/Edge, HTTPS 또는 localhost |
| 밝기 | CdS ADC 원시값 0~1023. 보정 없이 lux로 표시하지 않음 |
| 온습도 실패 | null은 — 또는 값 없음. 실제 0과 구별 |
| 이력 | 최근 밝기 60개, 탭 메모리이며 새로고침 시 소멸 |
| 오래됨 | 수신 중단 또는 4초 이내 오래됨 표시 확인 |
| 명령 | 요청번호 → 전송 대기 → 보드 ACK → 보고 상태를 구별 |
| 명령 실패 | 시간 초과는 적용 여부 미확인. 임의 자동 재전송 금지 |

## 개인 화면 설계 적용

주제는 작업 공간의 밝기·온습도 확인과 조명 제어다. 첫 화면은 연결 상태·마지막 정상 수신 시각 → 현재 센서값 → 밝기 이력 → LED 제어 순서로 배치한다. 상태는 글자와 아이콘으로도 표현하고, 버튼은 키보드로 접근할 수 있게 한다. 현재값이 오래되면 과거 값을 정상 현재값처럼 표시하지 않는다.

| 확인 상황 | 기대 결과 | 이번 확인 상태 |
| --- | --- | --- |
| 연습 데이터 | 실제 측정 아님 표시 | NOT_RUN |
| USB 정상 | P01 수신, 마지막 정상 시각 갱신 | NOT_RUN |
| 센서 null | 값 없음, 0으로 대체하지 않음 | NOT_RUN |
| USB 분리 | 수신 종료/오래됨 표시, 현재값과 이력 구별 | NOT_RUN |
| LED 명령 ACK 누락 | 시간 초과·적용 미확인 | NOT_RUN |
| LED 정상 | ACK·보고 상태·실제 LED를 각각 관찰 | NOT_RUN |
| 키보드·좁은 화면 | 초점 확인·주요 조작 가능·가로 넘침 확인 | NOT_RUN |

원격 영상 대시보드·조이스틱 게임은 기존 구현이며, 10/29 P01 개인 대시보드 구현과 동일하지 않다. 이번 갱신에서는 교안 정리와 개인 설계·시험표를 작성했다. P01 개인 대시보드 코드 제작·실제 회로 시험·제출 ZIP 완료로 표시하지 않는다. USB 연결 해제는 보드 STOP이 아니며 자동 모드는 계속될 수 있으므로 종료 전에 자동 해제·LED 끄기를 별도로 확인한다.
