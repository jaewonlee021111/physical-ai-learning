# 이미지 분류·Edge Impulse·재학습

## 수업의 흐름

기존 사진 수집 대시보드에서 물체 사진을 모으고 Edge Impulse의 이미지 처리·특징 생성·전이학습을 거쳐 모델을 만든다. 모델을 Arduino 라이브러리로 내보내 ESP32에서 실행하고 로컬 웹으로 영상과 결과를 관측한다. 강사는 콜라·칙촉 분류를 시도한 뒤 오분류를 발견했고 배경 클래스를 포함한 사진을 추가해 재학습했다.

물체 대신 마우스 패드나 조명에 반응하는 사례가 있었다. 학습 화면의 높은 수치만으로 현장 동작을 보장할 수 없고, 다른 조건의 실제 입력으로 재확인해야 한다.

## 재현 절차

1. 클래스 이름과 수집 기준을 정한다. 예: `background`, `cola`, `cookie`. 배경에는 물체가 없는 장면과 헷갈리는 물체도 넣는다.
2. 조명·각도·거리·배경을 바꾸며 별도 세션으로 촬영한다. `dataset.py capture`는 JPEG 디코딩 성공 후 저장한다.
3. `dataset.py audit`로 깨진 파일·클래스별 학습/시험 존재·중복 픽셀·라벨 충돌을 확인한다. 세션 단위로 testing을 지정하며 비슷한 연속 프레임이 양쪽에 들어가지 않게 한다. 해시 검사는 완전히 같은 픽셀만 잡으므로 유사 사진 검토는 추가로 필요하다.
4. Edge Impulse Studio에서 같은 분할로 사진을 업로드한다. API 키는 로컬 `.env`에만 보관한다. 현재 도구는 클라우드 업로드·학습 API를 자동 호출하지 않는다.
5. 입력 크기·색상·resize/crop 방식을 기록하고 Image 처리와 이미지 전이학습을 설정한다. 실제 배포 모델의 metadata와 카메라 전처리를 일치시킨다.
6. 모델 크기·RAM·Flash·지연을 보고 타깃에 맞는 모델을 선택한다. 학습 epoch·learning rate와 클래스별 결과·혼동행렬을 기록한다.
7. 별도 촬영 세션을 모델 시험에 사용한다. 틀린 장면의 조명·배경·거리와 원본을 기록한다. 결과를 보고 시험 사진 자체를 학습에 편입했다면 새로운 독립 시험 세트를 확보한다.
8. 추가 수집 → 재학습 → 새 모델 내보내기 → 펌웨어 재빌드·업로드 → 같은 조건 및 새 조건 시험을 수행한다.

## 용어 정리

- 전이학습은 사전 학습된 가중치의 특징을 새 문제에 활용하는 것이다. 모델 구조만 가져와 무작위 가중치부터 학습하는 것은 전이학습과 다르다.
- MobileNet의 `0.35` 같은 폭 계수(alpha/width multiplier)는 채널 수·모델 크기에 관련된다. **int8/float 양자화 설정과 다른 개념**이다.
- int8 양자화는 수치 표현을 바꿔 메모리·연산 부담을 줄이는 방법이다. 정확도 영향은 실제 데이터로 확인한다.
- 이미지 분류는 사진 전체의 클래스 점수다. 물체 위치·바운딩 박스를 주는 객체 검출과 다르다.
- Feature Explorer의 분리된 점 분포는 특징 관찰 자료이며 독립 시험 정확도의 대체가 아니다.

## 평가 입력 형식

`evaluate.py`는 보드/모델에서 따로 수집한 결과를 아래 형식으로 읽는다. 다음 한 줄은 **형식 설명용 숫자**이며 실제 모델 결과가 아니다.

```json
{"id":"day2_001","actual":"cola","scores":{"background":0.1,"cola":0.8,"cookie":0.1},"inference_ms":120}
```

행은 실제 클래스, 열은 예측 클래스인 혼동행렬·클래스별 precision/recall/F1·Macro-F1·평균 추론 시간을 계산한다. 빈 입력·중복 ID·잘못된 클래스·NaN·확률 합 오류를 거절한다. 학습 평가 숫자를 임의 생성하지 않는다.
