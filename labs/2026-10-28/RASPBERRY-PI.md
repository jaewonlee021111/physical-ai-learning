# 라즈베리파이 헤드리스 초기 설정

강의에서 라즈베리파이 5를 대상으로 microSD·USB 리더기·Raspberry Pi Imager·SSH·Connect·전원·부팅 문제를 다뤘다. 이 환경에는 장비가 없으므로 아래는 재현 안내이며 실제 설치 완료 기록이 아니다.

## 순서

1. 모델과 microSD를 확인하고 기존 데이터가 있으면 백업한다. Imager 쓰기는 선택한 저장 장치의 내용을 지운다. 대상 드라이브를 정확하게 확인한다.
2. [공식 Imager](https://www.raspberrypi.com/software/)에서 해당 보드와 Raspberry Pi OS 64-bit를 선택한다. 로봇 키트 라이브러리가 특정 OS를 요구하면 키트 설명서도 대조한다.
3. 호스트명·사용자 계정·시간대·지역과 연결할 Wi-Fi를 설정한다. 비밀번호는 공개 문서·채팅 로그·저장소에 남기지 않는다.
4. 원격 접근에서 SSH를 활성화하고 비밀번호 인증 또는 공개키 인증을 정한다. Connect를 사용할 경우 별도 Raspberry Pi 계정과 해당 환경의 지원 조건을 확인한다.
5. 정확한 microSD에 쓰기·검증을 마친 뒤 분리하고 보드에 삽입한다. 전원을 연결하고 부팅을 기다린다.
6. 같은 네트워크에서 `ssh 사용자명@호스트명.local`로 연결한다. 이름이 안 풀리면 공유기 장치 목록의 본인 보드 IP를 확인한다. SSH 암호는 터미널에 직접 입력한다.
7. 읽기 전용으로 `hostname`, `uname -a`, `cat /etc/os-release`를 확인해 실제 장치·OS에 접속했는지 기록한다. Connect는 원격 화면 접근 경로로 별도 확인한다.

## 실패 원인 분리

| 현상 | 확인 |
| --- | --- |
| SD가 안 보임/쓰기 실패 | 리더기·삽입 방향·어댑터 lock·다른 포트·쓰기 권한 |
| OS 기록 후 부팅 안 됨 | 이미지 검증·보드 모델·SD 상태·전원/케이블 |
| Wi-Fi/SSH 안 됨 | SSID·국가·인증·같은 LAN·SSH 활성화·IP·클라이언트 격리 |
| LED 점멸 반복 | 보드별 공식 진단 패턴 확인. 깜빡임 하나로 성공/실패 단정 금지 |
| 전압 부족/장치 불안정 | 충전기 전체 W가 아니라 해당 전압에서 공급 가능한 전류·케이블 확인 |

## 자막 설명을 그대로 따르지 않을 부분

- Pi 5는 2.4GHz와 **5GHz Wi-Fi를 지원**한다. ESP32의 일반적인 2.4GHz 제약과 혼동하지 않는다.
- Pi 5의 권장 전원은 5V급 5A 조건을 충족하는 적절한 공급장치다. ‘총 27W 이상’이라는 표시만으로 모든 충전기가 적합한 것은 아니다. 공식 27W USB-C 공급장치를 기준으로 확인한다. 5V 3A 사용은 USB 주변 장치 전류 제한 등 조건이 있다.
- SSH와 Connect는 별도 접속 방식이다. 둘 다 켜졌다는 사실만으로 보드 접속이 검증되는 것은 아니다.
