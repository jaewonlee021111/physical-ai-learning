# 아이디어 그룹화와 최종 범위

이전에 제시한 15개 아이디어를 주제 관점에서 정리한 개인 기록이다. 기능 하나가 같다는 이유만으로 무조건 같은 주제로 묶지 않는다.

| 주제 | 연결되는 아이디어 |
| --- | --- |
| 목적지 이동·공간 탐색 | 목표 그림까지 자율 이동, 거리·방향 명령 이동, 장애물 회피, 빈 주차 공간 탐색 |
| 사람과 상호작용하는 동반 로봇 | 손방향 이동, 음성 제어, 특정 얼굴 추종, 대상 주시, 박수·소리에 애교, 사람 행동 모방 |
| 환경 상태 확인·관리 보조 | 식물 잎 상태 관리 알림, 구석 청소 필요 판단, 뜨거운 물체 탐지·접근/회피 |
| 접근성·의사소통 보조 | 수어 지원 |
| 시각 신호에 반응하는 주행 | 공 색에 따른 속도 변화, 목표 그림 추종과 방향 지시 해석 |

아이디어는 복수 주제와 연결될 수 있다. 이것은 자동 군집 알고리즘 결과나 팀원의 투표 결과가 아니다.

## 선택한 주제

그림·이동 표지판에 반응하는 4륜 라즈봇. **표지판 발견 → 접근 → GOAL 정지 또는 화살표 회전**을 기본으로 하고 손동작을 확장한다. 핵심은 눈앞의 시각 지시를 이해해 실제 이동으로 이어지는 것이다.

## 먼저 만들 범위

- GOAL 한 장을 인식하고 안전 거리에서 정지.
- 좌우 화살표를 추가해 회전·다음 표지판 탐색.
- 신호 소실·거리 실패·장애물·같은 신호 재실행 처리.
- 손동작은 기본 표지판 흐름의 실제 검증 후 추가.
