# 역할·백로그·일일 공유 초안

실제 담당자 이름·시간 약속은 팀에서 확정한다. 아래 상태는 실행 완료를 가정하지 않는다.

| ID | 작업 | 역할 | 완료 기준 | 상태 |
| --- | --- | --- | --- | --- |
| W01 | 카메라·표지판 인식 | 인식 담당 | GOAL·좌·우 종류·위치·관측 시각 제공 | 팀에서 확인 |
| W02 | 모터·초음파 | 하드웨어 담당 | 전후진·회전·거리값·측정 실패 구분 | 팀에서 확인 |
| W03 | GOAL 접근·정지 | 제어 담당 | 중앙 정렬·감속·거리 정지 실물 확인 | 팀에서 확인 |
| W04 | 상태 전환·예외 | 통합 담당 | 신호 소실·중복·센서 실패·장애물 시험 | 팀에서 확인 |
| W05 | 실험 기록·시연·웹 발표 | 공동, 주 담당 지정 | 원본 버전·배선·시험·시연·배포 주소 | 미작성 |

인식·센서를 먼저 각각 확인하고 W03부터 통합한다. 제어 담당은 ‘어떻게 움직일지’, 통합 담당은 ‘언제 상태를 바꿀지’를 책임진다.

## 일일 공유

```text
오늘 실제 끝낸 것:
관련 커밋/PR/시험 결과:
막힌 점과 재현 방법:
도움이 필요한 사람/결정:
다음 작업과 완료 조건:
```

검토자는 성공 사례뿐 아니라 오류 재현·입출력 계약·문서도 확인한다. 역할·기준을 바꾸면 사유와 영향을 요구·작업·시험에 같이 반영한다.
