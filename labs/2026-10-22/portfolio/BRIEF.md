# 포트폴리오 고도화 기획

기존 [HTML](../../../web/index.html)·[React](../../../web/react/src/main.jsx) 버전을 이어서 수정했다. 새로운 경력이나 학력을 만들어 넣지 않고, 저장소에서 확인할 수 있는 작업만 보여준다.

- 독자: 프로젝트를 검토하는 동료·면접관.
- 목적: 무엇을 만들었는지와 어떤 근거로 검증했는지 두 번의 클릭 안에 확인하기.
- 주요 행동: 분야 필터 → VISION LAB 카드 → 날짜별 실습·실행 결과 확인.
- 화면: 모바일 1열·태블릿 2열·넓은 화면 3열. 메뉴는 작은 폭에서 접는다.
- 상호작용: 메뉴 열기·닫기, Escape, 프로젝트 분야 필터, 문의 입력 검사. 폼은 실제 전송하지 않는다.
- 변경: 10/22 세션·비전 프로젝트 추가, 날짜 문구 갱신, HTML·React 공통 파비콘과 Open Graph 제목·설명 추가.

## 디자인 방향 비교

| 방향 | 특징 | 판단 |
| --- | --- | --- |
| 종이 노트 | 밝은 배경·기록 중심 | 긴 글 읽기에 적합 |
| 어두운 실험실 | 영상·계측 수치 중심 | 비전 대시보드에 선택 |
| 편집형 포트폴리오 | 넓은 여백·카드·학습 이력 | 기존 포트폴리오 디자인을 유지 |

기존 HTML·React 버전에서 같은 데이터를 공유하도록 `web/shared.mjs`를 수정했다. 디자인 방향표는 재구성한 기획이며 강사의 생성 시안을 복제한 결과가 아니다.

## 배포 범위

이번 작업은 GitHub 소스와 React 정적 빌드 갱신까지 수행한다. 새 공개 URL 배포 완료를 의미하지 않는다. GitHub Pages는 HTML/CSS/JS 빌드 결과를 호스팅할 수 있지만 Flask 카메라 서버를 실행하지 못한다. 로컬 비전 앱을 정적 포트폴리오에 직접 넣지 않고 저장소의 실습 안내로 연결한다.
