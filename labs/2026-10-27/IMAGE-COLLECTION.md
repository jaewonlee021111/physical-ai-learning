# 이미지 수집과 다음 날 학습 연결

기존 카메라 펌웨어의 **한 장 JPEG 응답 URL**을 준비한다. 이 서버는 카메라 펌웨어를 대신하지 않는다. 예시 IP는 문서용이므로 실제 보드 주소로 바꾼다.

```sh
# macOS/Linux. PowerShell은 $env:CAPTURE_URL="http://보드주소/capture"
export CAPTURE_URL=http://보드주소/capture
python -m uvicorn collector:app --host 127.0.0.1 --port 8002
```

`http://127.0.0.1:8002/`에서 클래스 `cola`를 정하고 한 장 촬영 또는 연속 촬영한다. 입력 칸·버튼에 초점이 없을 때 스페이스바도 촬영한다. 흐리거나 대상이 없는 사진은 삭제하고 클래스별 ZIP으로 받는다. 기본 저장 경로는 `runtime/dataset/cola/`다. 영어·숫자·밑줄·하이픈만 클래스 이름에 쓴다. 연속 촬영 중 중지는 현재 요청 이후 적용된다.

원본 JPEG는 미리보기 대신 촬영 결과 목록에서 확인한다. 강의의 실시간 카메라 프리뷰와 달리 이 재구성 버전은 저장된 사진을 보여준다. 다운로드 응답 8MB 제한과 이미지 디코딩 검사를 수행한다. 인증이 없는 로컬 수집 도구이므로 loopback에서 실행한다. 보드 연결 실패는 502, URL 미설정은 503이다.

클래스별 이미지 수가 같아도 데이터 품질이 보장되지는 않는다. 거리·각도·조명·배경을 다양하게 하고 다른 촬영 묶음을 평가용으로 남긴다. 개인 얼굴과 주변 개인정보가 담긴 사진은 공개 저장소에 올리지 않는다. 합성 JPEG 시험 데이터는 자동 검사에서만 생성하며 수업의 실제 촬영 데이터로 표시하지 않는다.
