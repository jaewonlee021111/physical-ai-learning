# 이 실습의 데이터 계약

| 항목 | 뜻 | 기록 규칙 |
| --- | --- | --- |
| sensor_id | 장치 식별자 | S01처럼 S 뒤에 숫자 두 자리인 문자열. 같은 장치의 다른 시각 기록은 허용한다. |
| location | 기록한 위치 | 입구, 창고, 실습실, 복도 중 하나. |
| temperature_c | 측정한 섭씨 온도 | 측정값은 숫자. 0~50은 이 실습의 입력 점검 규칙이며 실제 장비의 안전 범위가 아니다. 미측정은 CSV 빈칸, JSON null이다. 0은 실제 측정값이다. |
| measured_at | 기록한 날짜와 시각 | YYYY-MM-DD HH:MM 모양의 문자열. 예: 2026-10-08 10:00. 날짜 파싱 코드를 만들 필요는 없다. |
| active | 기록에 적힌 가동 상태 | CSV에는 true/false 글자, JSON에는 따옴표 없는 true/false 불리언. Python에서는 True/False. |

열 순서는 sensor_id,location,temperature_c,measured_at,active이다. 헤더 뒤 한 레코드가 한 번의 측정 기록이며 다섯 필드를 갖는다. sensor_id와 measured_at의 조합이 같으면 중복 여부를 확인한다.

미측정은 수치를 모른다는 뜻이다. 0이나 평균으로 채우지 않는다. 자료 형식에는 빈칸/null로 보존하고, 후속 확인이 필요하면 이슈에 보류로 기록한다. 알 수 없는 잘못된 값은 원문을 보존하고 지시가 있을 때만 수정한다.

별도 quoting 카드의 '창고, 안쪽'은 쉼표가 포함된 문자열을 설명하는 예외 사례다. 정규 위치 목록에 자동 추가하지 않는다.
