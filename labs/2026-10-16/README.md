# Git/GitHub 실제 실습

`python scripts/git_practice.py`로 임시 저장소에서 실제 Git 명령 27개를 실행한다. save → diff → add → cached diff → commit, feature 브랜치, main과의 의도한 충돌, 충돌 수정 커밋, 로컬 bare remote로 push, clone·fetch·pull과 log·status를 검증한다.
