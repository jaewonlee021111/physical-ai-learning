## 배운 내용의 연결

1. **데이터:** 기록 단위·출처·항목·단위·빈값을 정한다. CSV와 JSON에서 구조와 자료형을 보존한다.
2. **Python:** 입력 검증·조건·반복·함수·파일 처리로 결과를 만든다. 트리·예약·측정 분석·로그 검사에서 경계값과 실패를 다룬다.
3. **Git·AI:** 요구와 완료 조건을 적고 작은 변경으로 구현한다. 브랜치·PR·diff·시험·실행 안내로 공유하고 다음 작업에 필요한 컨텍스트를 남긴다.
4. **웹:** HTML의 의미·CSS의 반응형 배치·JS/React의 상태로 화면을 만든다. 배포·모바일·폼·피드백 반영도 따로 확인한다.
5. **비전:** 카메라 입력을 YOLO 검출·추적·구역 알림·방향 집계·이벤트 저장으로 연결한다. 처리 지연·프레임 나이·실패 장면을 함께 본다.
6. **하드웨어:** 핀·전원·센서·모터·통신을 이해한다. ESP32 Wi-Fi/BLE·카메라와 UNO 입력·출력·LCD·키패드·조이스틱을 연결한다.
7. **대시보드:** 현재값·과거 이력·원시값·수신 시각·명령 응답을 구별해 판단을 돕는다. 센서값 없음과 0, 전송과 ACK는 다르다.
8. **기획:** 문제·범위·역할을 정하고 요구 → 설계 → 작업 → 시험 → 결과·인계를 연결한다. 기대와 실제 관찰·증거를 분리한다.

표지판을 인식해 접근하고 GOAL에서는 정지, 좌우 화살표에서는 회전하는 4륜 로봇이다. 인식·모터/거리·접근 제어·상태 전환으로 나누고 GOAL 접근·정지부터 완성한다. 손동작은 후속 확장이다. [개인 기획 초안](../labs/2026-10-30/PROJECT-PLAN.md)에 요구·작업·시험과 초기 수치를 연결했다. 팀 승인·담당자 배정·실물 완성 기록은 아니다.

- **기존 10/08~10/26 코드:** 날짜별 폴더에 유지했다. Python·브라우저·보드 빌드·실제 예제 이미지 추론의 기존 결과는 각 검증 문서를 따른다. 이번 정리에서 전부 재실행한 것은 아니다.

- **이번 추가:** 공개 10개 수업의 개념·전체 단원·요구 산출물, 기존 10/26 요약, 10/29 설계·확인표, 10/30 라즈봇 개인 기획 초안이다.
