# 2026-10-28 · Edge AI 이미지 분류와 팀 프로젝트 협업

[전체 정리](../README.md) · [코드·실행 안내](../../labs/2026-10-28/README.md)

## 수업 내용

- 기존 사진 데이터 수집을 마무리하고 Edge Impulse에서 이미지 처리·특징 생성·전이학습·혼동행렬을 확인했다.
- ESP32에 맞는 모델을 Arduino 라이브러리로 내보내 추론 펌웨어와 로컬 웹 대시보드로 연결했다.
- 콜라·칙촉 오분류에서 배경·조명·각도 영향을 확인하고 background 등 사진을 추가한 뒤 재학습했다.
- 팀 주제·모임·역할과 하드웨어 범위를 정하고 개별 아이디어 발산 → 비슷한 주제 그룹화 → 최종 피칭을 실습했다.
- 팀 GitHub 저장소와 collaborator 초대, 개인 브랜치·PR·검토·merge를 취미 소개 사이트로 연습했다.
- 스프린트·일일 공유·리뷰·비동기 영상 등 원격 협업 방식을 소개했다.
- Raspberry Pi Imager로 microSD에 OS를 쓰고 SSH·Connect·Wi-Fi·전원·부팅과 접속 오류를 확인했다.

## 만든 파일과 실제 상태

사진 JPEG 수집·세션 분할·중복/라벨 점검, 혼동행렬·Macro-F1 계산, XIAO ESP32S3 Sense 추론·웹 관측 펌웨어 소스, 실제 로컬 Git 브랜치 병합 예제와 팀 기획 자료를 추가했다. Python 11개 검사는 통과했다. 기존 팀원2 축구 취미 PR은 병합 완료로 확인했다.

실제 강의 사진·Edge Impulse 모델·프로젝트 키와 보드가 없어 새 모델 학습·모델 포함 컴파일·실물 추론·라즈베리파이 설정은 미수행이다. 자막을 읽고 핵심 화면을 대조한 범위이며 전체 영상을 매 순간 시청한 것은 아니다. [출처·정정·제한](../../labs/2026-10-28/SOURCES.md)을 따른다.
