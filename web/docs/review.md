# 자동 검수와 수정 내역

| 검수 상황 | 발견·확인 내용 | 반영한 변경 | 재확인 |
| --- | --- | --- | --- |
| React 프로덕션 빌드 | 빈 data CSS import를 파일로 해석해 빌드 실패 | 불필요한 import 삭제 | Vite 빌드 성공 |
| HTML/React 문의 폼 | 전송 기능이 없는 폼에서 완료 의미를 분명히 해야 함 | 성공 안내에 입력 검사만 완료·미전송 표시 | 실제 브라우저 정상/실패 입력 확인 |
| 잘못된 입력 | 어떤 필드를 고칠지 접근성 안내 필요 | 필드별 오류·aria-invalid·설명 연결·첫 오류 포커스 | 정상/빈 입력 검증 |
| 분야 필터 | 결과 개수와 선택 상태 확인 필요 | aria-pressed·aria-live 개수 제공 | HTML Web 2개, React Python & AI 3개 확인 |
| React 모바일 메뉴 | 메뉴 버튼에 포커스가 있을 때 Escape가 닫히지 않음 | 키 처리를 nav에서 header로 이동 | 수정 후 모바일 재검사 |
| 모바일 첫 화면 | 보드의 영문 제목과 보조 설명이 겹침 | 모바일에서는 설명을 정적 배치로 변경 | 두 버전 모바일 재캡처 |
| 서브폴더 배포 | React 자산의 절대 경로는 프로젝트 Pages에서 깨질 수 있음 | base './', HTML 버전 상대 경로 | 빌드본 버전 전환 성공 |

검토자는 자동화된 코드·브라우저 점검이다. 수업 팀원이 남긴 피드백으로 표시하지 않는다.
